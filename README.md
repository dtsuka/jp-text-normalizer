# 紛れ込み文字チェッカー

日本語テキストに紛れ込む「**見た目は同じなのに別のUnicode文字**」を検出し、正規化するWebアプリです。
PDF・Webページ・ワープロや表計算ソフト・チャットなど他のアプリからのコピー＆ペースト、OCR結果、フォントや変換ツールの都合などで、康煕部首・結合濁点・互換漢字・ゼロ幅文字などが混入することがあります。
テキストエリアに貼り付けると、問題のある文字をその場でハイライトし、文字・コードポイント・Unicode名・変換後の文字を一覧表示します。「正規化する」ボタンで変換後のテキストを作り、ワンクリックでコピーできます。

**公開ページ: https://dtsuka.github.io/jp-text-normalizer/** （[サンプル入りで開く](https://dtsuka.github.io/jp-text-normalizer/?sample)）

- 静的サイト（HTML / CSS / JavaScript のみ、ビルド不要、外部CDNなし）
- 入力したテキストは外部に送信されません（すべてブラウザ内で処理）
- オフラインでも動作（`index.html` をダブルクリックで開いても動きます）

## 使い方

1. 入力欄にチェックしたいテキストを貼り付ける（「サンプルを挿入」で例を試せます）
2. 右側のプレビューで問題の文字がハイライトされます（赤=要修正、黄=要確認、青=参考）。マウスを重ねると詳細を表示
3. 「検出結果（カテゴリ別）」で、変換するカテゴリをチェックで選ぶ
4. 「正規化する」→「コピー」

指摘一覧の行をクリックすると、入力欄の該当箇所が選択されます。

## 検出する文字

| カテゴリ | 例 | 既定の処理 |
|---|---|---|
| **康煕部首** U+2F00–2FDF | ⽇→日、⾼→高、⼾→戸 | 変換（NFKC。⼾⾭⿈⿊ は日本語の字形 戸青黄黒 に） |
| **CJK部首補助** U+2E80–2EFF | ⻑→長、⻄→西、⺠→民、⻘→青、⻝→食、⻩→黄、⻤→鬼 | 変換（Unicode の EquivalentUnifiedIdeograph.txt に基づく対応表）。⻓⻔ など中国簡化字形の部首は提案のみ |
| **結合文字の濁点・半濁点** U+3099/309A | か＋゙ → が | NFCで合成。合成できないもの（あ゙ など）は指摘のみ |
| **単独の濁点・半濁点** ゛゜ | か゛→が | かなの直後で合成できる場合のみ合成 |
| **分解されたアクセント記号** | e＋◌́ → é | NFCで合成 |
| **CJK互換漢字** U+F900–FAFF, U+2F800–2FA1F | 神（U+FA19）→神（U+795E） | 正規分解のあるものだけ変換。﨑（U+FA11）など正規分解のない12字は正規の漢字なので参考表示のみ |
| **異体字セレクタ** U+FE00–FE0F, U+E0100–E01EF | 葛󠄀（IVS） | 削除（絵文字の FE0F は対象外） |
| **ゼロ幅・不可視・制御文字** | ZWSP(U+200B)、BOM(U+FEFF)、ソフトハイフン(U+00AD)、方向制御、制御文字 | 削除（U+2028/2029 は改行に） |
| **特殊な空白** | NBSP(U+00A0)、U+2000–200A など | 半角スペースに |
| **全角スペース** U+3000 | 「　」 | オプションで検出したときのみ（既定は変換しない） |
| **半角カナ** U+FF61–FF9F | ｶﾞｲﾄﾞ｡→ガイド。 | 全角に |
| **全角英数字** | ＡＢＣ２０２６ | 既定は変換しない（オンで半角に） |
| **囲み文字・組文字・単位記号** | ①、㈱、㍿、㌔、㎡、№ | 既定は変換しない（オンでNFKC展開: ①→1、㍿→株式会社） |
| **欧文合字** U+FB00–FB06 | ﬁ→fi、ﬂ→fl | 分解 |
| **縦書き用・小字形の互換文字** | ︵︶︒︙ | 通常の記号に |
| **簡体字** | 这→這、说→説、门→門、车→車、东→東、长→長 | 提案（既定は変換しない） |
| **繁体字・旧字体** | 說→説、稅→税、戶→戸、黃→黄、國→国 | 提案（既定は変換しない。JISにある旧字体は「参考」扱い） |
| **紛らわしい文字** | プ口グラム（漢字の口）→プログラム、ラ一メン→ラーメン、デ―タ→データ、コㅡヒー（ハングル）、Аpple（キリル文字のА） | 提案（既定は変換しない） |
| **CJK字画・漢字構成記述文字** | ㇀、⿰ | 指摘のみ |
| **私用領域（外字）** | U+E000–F8FF | 指摘のみ |
| **置換文字・不正な文字** | �（U+FFFD）、孤立サロゲート、非文字 | 指摘のみ |

### 対応表の規模

- 康煕部首: 214字（NFKC＋日本語字形の補正4字）
- CJK部首補助: 114字（うち中国簡化字形の部首22字は提案のみ、1字は対応字なし）
- 簡体字: 手作業の対応表 約560字 ＋ Unihan から自動生成した表 約2,240字（JIS X 0208/0213 にない簡化字のみ）
- 繁体字・旧字体: 約220字
- 紛らわしい文字: カタカナ語中の漢字12字、ダッシュ類10字、キリル・ギリシャ文字36字

JIS X 0208 の全文字（約6,900字）を入力しても「要修正」「要確認」が出ないこと（旧字体・全角英数字などの「参考」のみ）をテストで確認しています。

## 注意・制限

- 簡体字・繁体字・紛らわしい文字の判定は「提案」です。人名・固有名詞・中国語の引用などでは正しい場合があります。
- CJK互換漢字・異体字セレクタを変換すると、意図的に使い分けた字形（人名の異体字など）の区別が失われます。必要ならカテゴリのチェックを外してください。
- 〜（U+301C）と ～（U+FF5E）、−（U+2212）とハイフンなど、環境依存の記号の揺れは対象外です。
- 文字名は Unicode 18.0 のデータ（ツールで扱う範囲のみ）を同梱しています。

## ファイル構成

```
index.html        画面
style.css         スタイル
app.js            画面の処理
normalize.js      検出・正規化ロジック（ブラウザ/Node.js 両対応）
unicode-data.js   文字名・部首対応・簡体字表（tools/gen-data.py で自動生成）
tests/test.mjs    テスト（node tests/test.mjs）
tools/gen-data.py unicode-data.js の生成スクリプト
```

## 開発

```sh
node tests/test.mjs            # テスト
python3 -m http.server 8080    # ローカルで確認 → http://localhost:8080/
```

`unicode-data.js` を作り直す場合は、Unicode の UCD から `UnicodeData.txt`・`EquivalentUnifiedIdeograph.txt`・`Unihan.zip`（中の `Unihan_Variants.txt`）を `tools/ucd/` に置いて `python3 tools/gen-data.py` を実行します。

## GitHub Pages で公開

リポジトリを GitHub に push し、Settings → Pages で「Deploy from a branch」→ `main` / `/(root)` を選ぶだけで公開できます。
